# ADKOM Text Editor 1.0

A real code editor inside the Unity Editor. 100% Editor-only — nothing ships in your builds.

- Dockable tabs; sessions survive reloads, restarts, even crashes
- Fast: <15 ms typing in 5,000+ line files; word-level undo
- C# semantics: completion, live errors, Go to Definition, Find References, Rename, Format
- Multi-caret, column select, folding, snippets, bookmarks, Quick Open
- Find/Replace in Files with global undo
- Diff/Merge: files, folders, tabs, three-way — or as Unity's VCS diff tool
- Git: gutter markers, blame, history, stage/commit/push, branch tree
- Markdown: source coloring + rendered WYSIWYG
- Themes & keymaps: Visual Studio, VS Code, Rider
- Localized: EN, JA, KO, ZH-Hans, ZH-Hant
- Optional AI: GitHub Copilot, Ask Unity AI
- Stable scripting API + signed addons
- Spell check, reflection inspector, visual undo timeline
