## Mouse & universal gestures

- **Ctrl+Click** — Go to Definition (any layout); on links, open in the browser.
- **Alt+Click** — add a caret (multi-caret editing).
- **Double-click** selects a word (drag extends by whole words); **triple-click** selects the line (drag extends by lines).
- **Ctrl+MouseWheel** — zoom; **middle-click** a tab closes it; drag tabs to reorder; drag a selection to move it (hold Ctrl to copy).
- **F3 / Shift+F3** repeat the last search without the dialog, in every layout.
